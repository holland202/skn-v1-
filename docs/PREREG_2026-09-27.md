## Finding that motivates K1 (read from the code, not yet run)

`SwarmGossipProtocol.compute_betti_one` returns E − V + C, the cycle rank of the communication graph.
That is β₁ of the *graph*, not of the swarm's Vietoris-Rips complex: four nodes all in range give
6 − 4 + 1 = 3, although their filled tetrahedron has no hole. `gossip_step` treats any value above 0 as a
fault and calls `_formation_reconfiguration_protocol`, which **removes links** between the two
best-connected nodes until the count reaches 0. That is a tree, the most fragile connected graph. So
the guard, as written, weakens redundancy in every fully connected formation.

## K1: a real topology guard (`skn/topology.py`)

β₀ and β₁ of the Vietoris-Rips (flag) complex at radius r, computed exactly over GF(2) with NumPy
(boundary-matrix ranks). No GUDHI or ripser needed. `compute_betti_one` uses it; the old count stays,
renamed `graph_cycle_rank`. Fragmentation is β₀ > 1; a hole is β₁ > 0.

- **K1a** A ring of 6 at unit spacing, r = 1.1: β₀ = 1, β₁ = 1. With r = 2.0 (next-nearest links
  fill the triangles): β₁ = 0.
- **K1b (the anti-vacuity contrast)** Four nodes, all pairwise in range: the Rips β₁ = 0, while
  `graph_cycle_rank` = 3.
- **K1c** Two clusters of 3, farther apart than r: β₀ = 2.
- **K1d** The same results as a brute-force reference that builds the complex and reduces the matrices
  by plain Gaussian elimination, on 200 random point clouds (n ≤ 12).
- **K1e** In `skn.rendezvous`, the old guard fires the reconfiguration protocol at least once and cuts
  at least one link. The new guard fires it 0 times in the same run.

## K2: signed docking (`skn/ccpl.py`)

ML-DSA-65 (FIPS 204) signatures on the docking manifest, via the pure-Python `dilithium-py`. Each node
has a key pair. `ccpl_initiate_dock` signs SHA3-512 of the manifest (pose, alignment, strain, node ids,
nonce, time). The vault records the signature's digest and the public key's fingerprint. `verify_dock`
checks a dock record against a public key.

- **K2a** A genuine dock record verifies.
- **K2b** A manifest changed in any one field fails verification. So does the right record under
  another node's key, and so does a replayed nonce (the verifier keeps the nonces it has seen).
- **K2c (fail closed)** If `dilithium-py` is not installed, `ccpl_initiate_dock` does not lock. It
  returns `(False, "ML-DSA-65 unavailable")` and commits nothing.

**Limits, stated now.** `dilithium-py` is a reference implementation: not constant time and not
side-channel hardened. It is suitable for tests and simulation, not for an adversarial radio link. The
keys live in process memory.
